# Source attribution and redistribution note

The initial code in this repository derives from instructional ray-tracer material for CSC D18 attributed in the original source to **F. J. Estrada** (written Dec. 9, 2010 – Jan. 20, 2011; last updated Aug. 2017).

The original `RayTracer.c` file stated:

> Freely distributable for academic purposes only.

The included `svdDynamic.c` and `svdDynamic.h` retain the original notices naming **Thomas F. El-Maraghi**, copyright (c) 2000, and the later standalone-use modification note (FEG, Jul. 18, 2006).

The renderer also includes substantial subsequent implementations and cleanup, including geometric intersections and Phong lighting/shadows/reflections. Its instructional origin should not be presented as entirely original work.
